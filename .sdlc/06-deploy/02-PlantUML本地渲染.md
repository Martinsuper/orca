# 1. 发布状态与原则

本清单面向未来发生的代码发布、打包或安全策略变更；本次仅整理文档，**没有发布**。所有 checkbox 均保持未勾选，人员、版本、日期、窗口和测试结果均待实际发布时填写。

- PlantUML 图由用户配置的本地 JAR 与本机 Java 渲染；应用包当前不应被表述为内置或托管 PlantUML JAR。
- Orca 不调用外部 PlantUML 渲染 API；这不证明 Java/JAR/include 在所有环境下无法联网或读本地资源。
- 默认空 `plantumlJarPath` 表示功能未配置/禁用，不是安全沙箱或安全关闭证明。
- 任何涉及 security profile、JAR 可信来源、SSH 文档边界的变更，都必须先关闭 [待评审记录](../03-review/02-PlantUML本地渲染.md) 的 P0 项。

# 7. 回滚策略与触发条件

## 快速止损

1. **停止新渲染**：在受影响用户配置中清空 `plantumlJarPath`；该路径为空时组件不调用 Java，转为源码和配置提示。
2. **清除内存缓存**：重启应用；缓存不持久化，不能单独保证移除已显示 SVG 前的所有 UI 状态。
3. **版本回退**：停止候选包分发，回退到上一稳定版本；保留应用设置备份，避免无意丢失用户其它设置。
4. **安全事件**：若发现未批准的文件/网络访问、恶意 JAR、SVG 注入或 SSH 边界违规，停止发布并进入安全响应，不以“没有调用外部 API”作为结案理由。

## 回滚触发条件

- [ ] 未完成 P0 安全/边界决策却准备发布。
- [ ] 真实 JAR/Java 测试失败、超时残留、崩溃或严重资源异常。
- [ ] 验证到 JAR/include/URL 的实际行为与批准策略不一致。
- [ ] 出现 SVG 净化绕过、敏感错误信息泄漏或用户可利用的任意 JAR 执行路径。
- [ ] SSH/远端文档行为与已批准的执行边界不一致。
- [ ] 任一目标平台无法可靠禁用、回退或给出明确错误。
