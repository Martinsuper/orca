# 3. 风险与关闭条件

## P0：正式评审前必须定夺

| ID | 问题 | 影响 | 关闭条件 |
| --- | --- | --- | --- |
| P0-1 | 当前命令未强制 PlantUML security profile、URL allowlist 或本地路径 allowlist；可用行为取决于用户 JAR 与继承环境 | 无法承诺 include/资源访问不联网或不读本机文件 | 安全负责人明确接受现有信任模型，或设计并实施受控 profile/allowlist/隔离；用真实 JAR 验证结论 |
| P0-2 | 用户选择的可读 JAR 由 Java `-jar` 执行，当前无签名、版本、来源或主进程扩展名验证 | 恶意/错误 JAR 可带来本机代码执行风险 | 明确“用户自带可信 JAR”的产品与安全责任，或补充来源/校验机制 |
| P0-3 | SSH/远端 Markdown 文本可到客户端 renderer 后被本机 Java 处理，IPC 参数没有执行主机语义 | 可能与“执行主机拥有执行”原则产生边界争议 | 架构与安全确认这是允许的 UI 本地渲染；否则定义拒绝、远端执行或隔离方案 |

| ID | 问题 | 影响 | 关闭条件 |
