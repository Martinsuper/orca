## 1. 文档目的与事实边界

本文件整理既有 Todo 能力及原始需求证据，不代表新增开发、重新评审、测试通过或发布批准。原始 PRD 日期为 **2026-09-10**、状态为“已澄清”；该历史状态保留在第 8 节，当前因发现实现差异而标为“需求待差异确认”。

目标是在 Orca 右侧栏提供本机任务管理，帮助开发者按项目或全局范围记录、组织并推进工作。数据不做账号、云端或协作同步。

## 3. 角色、对象与权限

| 对象/角色 | 含义 | 可执行动作 | 可见范围 |

## 5. 业务规则与边界

| 编号 | 条件 | 处理结果 | 例外/优先级 |
| --- | --- | --- | --- |
| BR-01 | `repoId=''` | 作为全局任务/列表范围 | 非空 `repoId` 必须对应已注册项目后才可保存。 |
| BR-02 | 旧 Todo 缺 `listId` 等新字段 | 补入默认 Tasks 列表，重要=false、步骤=[]、备注='' | 加载迁移后随下一次保存落盘。 |
| BR-03 | 默认列表 | 不能删除 | 主进程拒绝删除。 |
| BR-03a | 删除单条任务 | 先进入轻量二次确认；取消或确认超时不删除，只有明确确认才删除 | 当前 UI 使用 3 秒二次点击确认；主进程删除接口本身不保存确认状态。 |
| BR-03b | 一级步骤 | 每个步骤独立保存 `done` 与 `updatedAt`；完成后继续显示，可单独恢复 | 步骤状态不自动完成或恢复所属任务；不支持二级嵌套。 |
| BR-04 | 任务完成 | `done=true`、设置 `completedAt`、取消待触发提醒资格 | 恢复后可再次出现在未完成视图。 |
| BR-05 | 截止日期已早于本地今天且未完成 | 在列表和计划内显示逾期 | 完成任务不显示逾期。 |
| BR-06 | 我的一天 | `myDayDate` 等于当前本地 `YYYY-MM-DD` 且未完成才显示 | 不因到期自动加入。 |
| BR-07 | SSH/folder workspace | Todo 不运行远端命令、不读取远端文件系统 | 任务数据和提醒属于 Orca 客户端本机 profile；不能据 SSH 断连推断任务或执行状态。 |

## 7. 非功能与平台边界

- **持久化**：本机 profile 保存；不承诺云端备份、跨机器一致性或删除恢复。
- **性能目标（历史目标）**：列表加载与常规操作 P99 < 100ms；当前没有本轮实测证据。
- **桌面端**：支持 macOS、Linux、Windows；日期使用本地日期语义，提醒存 epoch ms。
- **通知测试安全**：不得在用户桌面抢焦点或显示可见测试窗；自动化应使用 `ORCA_BACKGROUND_LAUNCH=1`，在隔离 CI/显示环境通过 CDP 验证。

## 9. 2026-09-20 已确认修复需求

本节补充而不改写第 8 节历史。用户已确认 **删除自定义列表时，列表内任务迁移到同一 scope 的默认 `Tasks` 列表**；不再要求连同任务永久删除。Todo 提醒仅允许本机桌面投递，禁止移动端 fanout。

| ID | 已确认行为与验收条件 |
| --- | --- |
| R8 | 切走 Todo Tab 再返回时保留当前 `scope` 与导航项；Project scope 的导航列表在 repo 变更、列表被删除或不存在时回退到 All，不能把旧 repo/list 导航用于新 scope。 |
| R9 | 任一 Todo 或列表 mutation 后，主进程向所有有效 Orca renderer 广播四类失效事件：项目任务、项目列表、全局任务、全局列表。每个 renderer 在 Todo 生命周期内订阅四类事件，按 payload scope 精确失效并刷新；卸载清理订阅，异步旧请求不得覆盖更新后的数据。 |
| R10 | 删除自定义列表后，任务迁移至同 scope `Tasks`，主进程同时广播任务与列表失效；执行操作的 renderer 也必须强制刷新，不能依赖“已加载”缓存短路。 |
| R11 | 任务保存中 `dueDate`、`reminderAt`、`myDayDate` 的 `null` 表示明确清空，`undefined` 保持既有字段以兼容旧调用。`reminderAt` 仅接受有限数值；值变化时清除 `reminderDeliveredAt`；任务完成后不得保有可投递提醒。 |
| R12 | My Day 聚合项的完成、删除、编辑必须以该 Todo 的 `repoId` 路由到实际 scope；编辑时列表候选和 `listId` 校验也必须以实际归属 scope 处理，禁止将项目任务复制/误写入全局。 |
| R13 | 启动扫尾将仅有 `todosByRepo` 或仅有 `todoListsByRepo` bucket 的已注销本地 repo 均视为孤儿并清理；现有 runtime-host 排除规则不变。 |

### 修复验收边界

- 单元测试：保存三态/null 清空、有限 reminder 校验、reminder 改值重置 delivered、完成清除提醒资格、列表删除迁移及强制刷新、四类事件的全窗口广播、订阅卸载与旧请求竞态、My Day 跨 scope 路由、孤儿单 bucket 清理。
- UI/重启/多窗口：后台 Electron 环境验证 Tab 导航回显、失效后刷新、删除迁移、重启持久化和两个 renderer 一致性；使用 `ORCA_BACKGROUND_LAUNCH=1` 与 CDP，禁止抢占用户桌面。
