# 1. 背景与目标

Orca 的 Markdown 用户需要在不离开桌面应用的情况下查看 `plantuml` 围栏中的图，而不是只能阅读源码。现有能力使用用户在设置中选择的本地 `plantuml.jar` 和本机可用的 Java，将图源码转成 SVG 后显示在 Markdown 预览、评论和富 Markdown 编辑器中。

- **目标用户**：编写、阅读或评审含 PlantUML 围栏 Markdown 的 Orca 桌面应用用户。
- **目标**：在已正确配置本地 JAR 和 Java 的前提下，将 PlantUML 围栏渲染为可阅读 SVG；配置缺失或渲染失败时保留源码并给出可操作错误，不破坏整篇 Markdown。
- **事实边界**：Orca 不把图源码提交给外部 PlantUML 渲染 API；这不等于 Java 或被选 JAR 被 Orca 强制禁网、禁本地资源读取。
- **成功定义**：用户能在三个既有入口看到同一图的本地渲染或明确的源码回退状态；不以“本次文档已补齐”替代真实测试、评审或发布结论。

# 4. 用户场景与产品行为

## S1：普通 Markdown 预览图

- **关联需求与优先级**：R1、R3、R5、R6 / P0、P1。
- **前置条件**：用户打开含 ` ```plantuml ` 围栏的 Markdown；已设置可读 JAR 且本机可启动 `java`。
- **触发动作**：Markdown 预览解析到语言类名为 `language-plantuml` 的代码块。
- **主流程**：预览组件将源码末尾换行规范化后交给 `PlantUmlBlock`；组件查缓存，未命中则经 preload 调用主进程；主进程以本地 Java/JAR 返回 SVG；客户端净化、修正比例并显示 SVG。
- **完成结果**：图以可缩放、可横向滚动的 SVG 容器显示，不套入无效的 `<pre>` 结构。
- **关键分支**：未配置或失败时显示“Diagram error”和具体错误，下面保留原始源码；组件卸载后不再更新已卸载视图。

## S2：富 Markdown 编辑器查看并编辑图源码

- **关联需求与优先级**：R1、R4 / P0。
- **前置条件**：富 Markdown 代码块语言为 `plantuml`，且源码非空。
- **主流程**：编辑器显示只读图预览并默认折叠语言选择、复制按钮和源码编辑区；用户点击图，或通过 Enter/Space 激活图预览后，展开源码；再次操作则折叠。
- **完成结果**：用户可在保留图预览的同时编辑源码；图预览不是对源码的替代，失败仍可阅读/修正源码。
- **关键分支**：空 PlantUML 块不显示预览；JAR/Java/渲染错误在图组件内回退，不阻断编辑器。

## S3：评论中的 Markdown 图

- **关联需求与优先级**：R1、R4 / P0。
- **前置条件**：评论 Markdown 的 fenced code child 带 `language-plantuml`。
- **主流程**：评论渲染器识别围栏并以 `PlantUmlBlock` 替代原始代码节点，同时在 `pre` 层解包，避免 `<div>` 被包在 `<pre>` 内。
- **完成结果**：评论入口的行为与普通 Markdown 预览一致。

## S4：配置缺失、JAR/Java 不可用或超时

- **关联需求与优先级**：R2、R4 / P0。
- **前置条件**：JAR 路径为空、不可读；Java 不在 PATH；JAR 无有效输出；或渲染超过 20 秒。
- **产品行为**：显示未配置、JAR 不可读、Java 未找到、stderr/无输出或超时信息；保留原 PlantUML 文本。
- **完成结果**：用户能继续阅读源码并到 Settings → Editor 修正 JAR 配置；不得把失败伪装为成功图。

# 5. 规则与边界

| 编号 | 条件/触发 | 处理结果 | 例外与优先级 |
| --- | --- | --- | --- |
| BR1 | 围栏语言匹配 `plantuml` | 使用 `PlantUmlBlock` | 其它语言按既有代码块/Mermaid 逻辑处理 |
| BR2 | JAR 路径为空或空白 | 不调用 Java，显示“未配置”回退 | 空路径是禁用，不是安全沙箱 |
| BR3 | 同一 `jarPath` 与同一源码已有成功缓存 | 直接复用 SVG，并刷新 LRU 最近使用顺序 | 错误不缓存，便于用户修复后重试 |
| BR4 | stdout 含 `<svg` | 即使 Java 非零退出也采用该 SVG | PlantUML 可能以 SVG 呈现语法错误行，优先于裸 stderr |
| BR5 | stdout 无 SVG | 返回 Java 缺失、stderr、异常或无输出错误 | 单图错误不得破坏其它内容 |
| BR6 | SVG 即将插入 DOM | 先以 DOMPurify SVG profile 净化，再做比例/画布处理 | 净化防御 DOM 注入，不等价于限制 JAR 进程能力 |
| BR7 | 文档源来自 SSH/远端工作区 | 图文本已到本地渲染器后，IPC 在客户端 Electron 主进程执行 | 不将 Java 调用路由至远端执行主机；这是需明确接受的客户端 UI 边界 |
| BR8 | 文档在 Web preload 环境 | 当前没有 `plantuml` preload API | 不承诺 Web 本地 JAR 渲染 |
